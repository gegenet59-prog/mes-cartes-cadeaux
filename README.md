# Mes cartes cadeaux

Mini-appli web pour ranger ses cartes et bons cadeaux et être prévenu 1 mois avant la date de fin.

- Ajout par photo, par capture d'écran ou par le menu « Partager » d'Android
- Lecture automatique de l'enseigne, du montant, de la date de fin et du code
- Alerte dans l'agenda 30 jours avant la fin de validité
- Les cartes restent uniquement sur le téléphone (sauvegarde possible dans un fichier)

La lecture automatique utilise Tesseract.js (licence Apache 2.0), fourni dans le dossier `ocr/`.
